axo — telegram mini app

English through coding

A coding game for kids that teaches English reading, writing, and vocabulary through the same commands children use to make Axo move, jump, and act. Built solo — research, branding, gameplay, and code — by Arina Bolotbekova.

the mechanic

One loop, two skills

Axo's core mechanic is grounded in Total Physical Response (TPR), a language-teaching method that pairs a spoken instruction with a physical action to anchor new vocabulary in memory. Axo applies the same instruction-then-action pairing to code.

01 · see

Read the command

A short English instruction appears — a word, a verb, a simple sentence.

02 · type

Type the code

The child writes the matching code command, connecting word to syntax.

03 · act

Watch Axo respond

Axo carries out the action immediately — the loop closes, the word sticks.
