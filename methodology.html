Integrated Language-Logic Acquisition (ILLA)

A dual-literacy framework for simultaneous second-language acquisition and computational thinking in children ages 5–9 — including learners with zero prior knowledge of English or the Latin alphabet.

the paradigm shift

Why language and logic belong in one lesson

Traditional early-childhood EdTech treats Second Language Acquisition (SLA) and Computational Thinking (CT) as separate silos. Standard ESL apps (Duolingo, Lingokids) rely on passive visual matching, translation, and rote flashcard repetition — they never engage procedural logic or spatial problem-solving. Standard coding apps (Lightbot, Scratch, CodeMonkey) teach algorithmic logic but assume native English literacy, treating text commands as abstract syntax rather than natural language to be acquired through phonics decoding.

ILLA bridges this gap. It operates on a single core innovation:

For a non-English-speaking child with zero prior language knowledge, target English vocabulary functions natively as an executable programming language.

By treating English words (go, turn-left, loop, if-ice, else) as direct action triggers inside a goal-oriented grid environment, ILLA enables young learners to simultaneously acquire three capacities:

Phonemic reading literacy

Letter–sound associations built through interactive audio-typing, one keystroke and one phoneme at a time.

Active spoken English

Imperative verbs and spatial structures used as functional tools of agency, not vocabulary items to memorize.

Computational thinking

Algorithmic planning, spatial logic, loops, and conditional branching (if / elif / else).

theoretical foundations

Four frameworks, one synthesis

ILLA is built on a synthesis of four established frameworks from cognitive science, linguistics, and computer science education.

Task-Based Language Teaching

Prabhu 1987 · Willis 1996 · Ellis 2003 · Nunan 2004

Language is acquired best when used as a tool to achieve a non-linguistic outcome. ILLA automates the TBLT cycle digitally: the learner evaluates a grid map to reach a goal (the reasoning gap), and focuses on solving the puzzle rather than memorizing rules — syntax is acquired implicitly.

Multisensory Synthetic Phonics

Systematic phonics principles, e.g. Jolly Phonics

Auditory phonemes (/g/, /o/) are paired with visual graphemes (G, O) and kinesthetic typing actions. The brain constructs a multi-layered neural map linking letter-sound, visual spelling, and motor execution.

Digitized TPR & Body-Syntonicity

Asher's Total Physical Response · Papert's LOGO Turtle

Typing turn-left or go causes an immediate, visible movement of the on-screen agent. The learner projects their own body schema into the spatial grid — language linked directly to physical action.

Coding as Another Language

Dr. Marina Umaschi Bers, 2018–2019

Constructing code relies on the same cognitive networks used for natural language literacy: [Subject] → [Verb] → [Object] maps onto [Condition] → [Command] → [Execution].

structural engine

The dual-phase cognitive cycle

Every ILLA lesson follows a strictly structured two-phase pipeline, taking zero-knowledge learners from raw sensory perception to active algorithmic execution.

Phase 1 · Learn

Phonemic-kinesthetic input & decoding

1 · Audio-visual pairing The child sees the target command (go) and hears its native pronunciation.
2 · Letter-by-letter tapping Each keystroke plays the isolated phonetic letter-sound: G → /g/, O → /o/. Visual, auditory, and kinesthetic inputs merge.
3 · Word synthesis Completing the keystrokes replays the full morpheme audio, solidifying the phoneme-to-grapheme bridge.
↓
Phase 2 · Challenge

Goal-driven spatial & algorithmic execution

1 · Evaluate the grid The child identifies a sprite, terrain elements, and an objective — a mouse that needs to reach a gift.
2 · Construct the sequence The child assembles a deterministic command sequence: go, turn-left, go.
3 · Immediate state change Hitting GO! executes the code in real time. An incorrect sequence moves the sprite exactly as written — non-punitive, visual debugging instead of lost hearts.
curriculum

The 40-lesson algorithmic roadmap

Forty systematically scaffolded lessons progress learners from single atomic commands to multi-branch conditional control structures — each module pairing an ESL focus with a computational one.

Module Lessons Linguistic focus (ESL) Computational focus (CT) Target syntax
1 · Atomic Action Commands 1–5 Directional & imperative verbs Single-step execution & state mapping go stop run back
2 · Spatial Orientation & Sequencing 6–10 Relative directions & sequential adverbs Spatial vectoring & multi-step planning turn-left turn-right move 2
3 · Parameterization & Quantifiers 11–17 Cardinal numbers, plurals & noun modifiers Variable parameters & direct inputs go 3 step 4 jump 2
4 · Procedural Repetition & Loops 18–25 Repetitive structures & duration Bounded iteration & loop blocks loop 3 [go] loop 2 [go, turn-left]
5 · Single-Branch Conditionals 26–33 Conditional grammar (if… then… else) Boolean state evaluation & branching if-path … end if-X … else … end
6 · Multi-Branch Environmental Chains 34–40 Complex hypotheses & environmental vocabulary Chained conditionals & dynamic state control if-ice if-fog elif else
modules 5 & 6 in depth

Teaching conditionals without a grammar book

Single-branch conditional with fallback

Linguistic objective: internalize natural English conditional fallback logic — "if [condition] happens, do A; otherwise, do B."
Computational objective: introduce binary decision trees and fallback execution paths. 

if-wall
    turn-left
else
    go
end

The child grasps else as a physical safety net for the agent — abstract grammar instruction for conditional clauses is eliminated entirely.

Multi-branch environmental chains

Linguistic objective: expand descriptive environmental vocabulary (ice, fog, hill) embedded directly in multi-clause conditional structures.
Computational objective: master multi-state evaluation and complex control flow (if → elif → else). 

if-ice
    slide
elif-hill
    climb
elif-fog
    wait
else
    go
end

The child develops an intuitive grasp of priority ordering in logic execution while absorbing high-level English sentence structures — syntax as an action trigger, not a rule to recite.

empirical case study

Spontaneous transfer in a 6-year-old learner

During early validation of the ILLA prototype with a 6-year-old child who had zero prior knowledge of English or the alphabet, a single 30-minute session produced three observable outcomes:

Rapid literacy decoding

Within 30 minutes, the child could independently type, decode, and read functional directional commands (go, turn-left).

Spontaneous spoken production

The child vocalized the target words out loud during execution — unprompted active production, not passive recognition.

Cross-contextual pragmatic transfer

Shortly after the session, in a public market, the child spontaneously substituted his native Russian ("иди направо") with the English acquired in-game — telling his brother "turn left!" and playfully adding "move move!" to passersby.

English is the programming language.

Significance for SLA research: this transfer demonstrates that ILLA achieves natural language acquisition rather than passive memorization. The target words were stored in the child's mind as active physical commands — functional instruments of agency.
