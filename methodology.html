English Through Logic

1 August 2026 · renamed 9 October 2026

The framework was called ILLA (Integrated Language-Logic Acquisition), and then CT-DGBLL, in 2026. Its name is now English Through Logic, which says what it does.

Young learners who cannot yet read English learn it as the language that runs a game. English is what is learned; logic, a system of rules the child wants to operate, is the route. In axo that system is a programming language, so each command is an English word and a program instruction at once.

A conceptual paper is in preparation. A link will appear here when it is available. axo is the app that implements the framework.

Earlier versions of this page described ILLA and CT-DGBLL and are superseded.
